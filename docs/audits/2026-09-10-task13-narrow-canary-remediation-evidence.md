## 5. F2 — unpredictable result-only nonce

**RED (pre-fix).** Adversarial fake that never reads the tool-result message and
fabricates `RESULT=<call-sentinel>|echo=<call-sentinel>` from the prompt:

```text
FAIL rejects a continuation that ignores the tool result   exit 0 (fabrication accepted)
FAIL requires the echo tool argument to equal the sentinel exit 0 (any {text} accepted)
FAIL refuses a nonce equal to the call sentinel            exit 0 (no independence guard)
FAIL proves the full Qoder tool round-trip                 (result-only markers absent)
Tests 4 failed | 18 passed (22)
```

**GREEN.** `RESULT_NONCE=<nonce>` is generated by crypto only AFTER a valid tool
call, must differ from the call sentinel, and the echo argument must equal the
call sentinel. The final response must contain `RESULT_NONCE=<nonce>`; the
fabrication built from the prompt sentinel is rejected, and the injected nonce is
asserted absent from request 1.

```text
LIVE_CANARY_RESULT_NONCE_ONLY_AFTER_TOOL_CALL=YES
LIVE_CANARY_TOOL_RESULT_IS_UNIQUE_INFORMATION=YES
LIVE_CANARY_FINAL_CAUSALITY_PROOF=PASS
Tests 22 passed (22)
```
